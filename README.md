# E-commerce SQL Analysis

## About the Project

The main purpose of this project is to use SQL queries to understand sales, customers, products, and orders.

## Objective

The main objectives of this project are:

* To understand the e-commerce dataset.
* To practice SQL queries.
* To analyze sales and orders.
* To find useful information about customers and products.
* To answer business questions using SQL.

## Dataset

The dataset contains information related to e-commerce transactions.

It includes details such as:

* Customers
* Products
* Orders
* Sales
* Quantity
* Price
* Order dates

## Tool Used

* SQL
* MySQL / SQL environment

## What I Did in This Project

### 1. Understanding the Data

First, I checked the tables and columns in the dataset.

I understood what information was available about customers, products, and orders.

### 2. Basic SQL Queries

I used SQL queries to:

* Select data
* Filter records
* Sort data
* Find unique values
* Use aggregate functions

### 3. Sales Analysis

I analyzed the sales data to find information such as:

* Total sales
* Number of orders
* Quantity sold
* Average sales
* Sales by product

### 4. Customer Analysis

I used SQL queries to understand customer information and their purchase activity.

### 5. Product Analysis

I analyzed products to find which products had more sales and which products were purchased more often.

### 6. Using SQL Functions

I practiced SQL functions such as:

* `SUM()`
* `COUNT()`
* `AVG()`
* `MAX()`
* `MIN()`
* `GROUP BY`
* `ORDER BY`
* `WHERE`
* `JOIN`

## Conclusion

Through this project, I practiced SQL using an e-commerce dataset.

I learned how to write SQL queries, combine tables, filter data, calculate values, and find useful information from the data.

This project helped me improve my understanding of SQL and data analysis.
